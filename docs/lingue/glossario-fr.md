# Glossaire français de Lode

Français de France, tutoiement, ton d'une appli pour étudiants : phrases courtes, directes, sans jargon.
Ce glossaire fixe les choix pour tous les catalogues `js/lingue/fr/*.js`.

| Italien | Français | Pourquoi |
|---|---|---|
| carta (del ripasso) | carte | Le mot des applis de flashcards en France (« cartes », « flashcards »). |
| carte del ripasso | cartes de révision | Plus clair que « flashcards » pour tout le monde. |
| ripasso / ripassare | révision / réviser | Ce que dit un étudiant français : « je révise ». |
| ripasso in tasca | révisions de poche | La phrase que reconnaît la barre en français. |
| esame | examen (« exam » à l'oral) | Terme général ; « partiel » seulement quand le texte parle du contrôle de mi-semestre. |
| appello | session / date d'examen | Le système français n'a pas d'« appels » : on parle de la date d'examen ou de la session. |
| sessione | session (d'examens) | Même mot en France. |
| libretto | relevé de notes | C'est le document qu'un étudiant français consulte pour ses notes. |
| media | moyenne | Mot naturel. |
| CFU | crédits (ECTS) | Les crédits européens ; « CFU » reste quand le texte parle du système italien. |
| trenta e lode | 30 avec mention (30 e lode) | Concept italien : on le garde expliqué. |
| base di laurea | note de départ de la licence (base di laurea, sur 110) | Concept italien, gardé et expliqué. |
| voto | note | « J'ai eu 15 en physique. » |
| orale | oral | « Simule l'oral », « oral blanc ». |
| interrogami | Interroge-moi | La commande reconnue en français. |
| barra | barre | La barre en haut de l'écran. |
| pillola | pastille | La forme arrondie de la barre ; « pilule » ferait médicament. |
| ★ Da esame | ★ À l'exam | Court, comme dit en amphi (« ça tombe à l'exam »). Le nom de section dans le vault reste « ★ Da esame » pour l'instant. |
| sbobina | transcription de cours (« sbobina » n'existe pas en France) | En France on parle de « cours retranscrit » / « ronéo » (médecine) ; « transcription » est le plus clair. |
| sbobinare | retranscrire | Idem. |
| trascrizione | transcription | Mot technique courant. |
| lezione | cours | En France on dit « le cours » (CM, TD) plutôt que « la leçon ». |
| videolezione | cours en visio | Le mot de tous les jours. |
| prof | prof | Identique. |
| appunti | notes (de cours) | « Mes notes » au sens prise de notes ; « notes » seules = aussi les notes d'examen, contexte décide. |
| focus | focus | Le mot est utilisé tel quel dans les applis (« session focus »). |
| timer di concentrazione | minuteur de concentration | Naturel. |
| pausa | pause | Identique. |
| piano (di studio) | plan (de révision) | « Mon plan jusqu'à l'exam ». |
| piano fino all'esame | plan jusqu'à l'exam | Direct. |
| programma d'esame | programme de l'examen | En France, le « programme » d'une matière. |
| argomento | chapitre / sujet | « Chapitre » pour un point du programme ; « sujet » si c'est un thème général. |
| temi d'esame | annales | Le mot de tous les étudiants français pour les sujets des années précédentes. |
| esercizio d'esame | exercice d'annale | Cohérent avec « annales ». |
| prova generale | examen blanc | Le terme exact en France. |
| quiz a crocette | QCM | Universel en France. |
| vault | coffre (vault Obsidian) | Obsidian FR dit « coffre » ; « vault » reste compris. |
| nota | note | Une note Obsidian. |
| cartella | dossier | Standard. |
| allenatore | coach | Mot courant dans les applis ; « entraîneur » sonne sport. |
| proposta (dell'allenatore) | suggestion | « Suggestions » comme dans les réglages. |
| Ripeti | Répète | La commande reconnue (« répète »), à l'impératif tutoyé. |
| «Cosa stampa?» | « Qu'est-ce que ça affiche ? » | La commande reconnue en français ; « affiche » est le verbe des cours de prog. |
| Segui il progetto | Suis le projet | La commande reconnue. |
| discussione (del progetto) | soutenance | En France on « soutient » un projet devant le prof. |
| turno dell'agente | dernier tour de l'agent | La commande reconnue (« dernier tour »). |
| agente | agent | Identique. |
| errori del compilatore | erreurs du compilateur | Identique. |
| sincronizzazione | synchro | Le mot court des applis. |
| password | mot de passe | Standard. |
| chiave (API) | clé | Standard. |
| la tua AI | ton IA | En français « IA ». |
| cervello locale | cerveau local | Garde l'image de Lode. |
| modello locale | modèle local | Standard. |
| impostazioni | réglages | Ton appli grand public (macOS dit « Réglages »). |
| benvenuto | bienvenue | Écran d'accueil. |
| trascina | glisse | « Glisse le fichier sur la pastille ». |
| slide | diapos | Ce que dit un étudiant (« les diapos du prof »). |
| frequenza | assiduité / présence | Le mot des facs françaises. |
| orario (delle lezioni) | emploi du temps | Standard (« EDT »). |
| lavoro / turni | boulot / horaires (de travail) | Registre familier mais clair ; « travail » dans les phrases neutres. |
| giorno cuscinetto | jour tampon | Image claire, usuelle en gestion du temps. |
| stare in pari | rester à jour | Naturel. |
| definizione | définition | Identique. |
| domanda per il prof | question pour le prof | Identique. |
| gioco | jeu | Identique. |
| sapevo / non sapevo | je savais / je ne savais pas | Idem ; dans « In tasca.md » les cases restent en italien pour l'instant. |
