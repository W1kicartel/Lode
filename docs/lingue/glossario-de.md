# Glossar Deutsch (de)

Wie Lode auf Deutsch spricht: «du», kurze Sätze, wie eine Lern-App für Studierende. Hier stehen die Wörter, die überall gleich bleiben müssen. Links das Italienische, dann das Deutsche, dann warum.

| Italiano | Deutsch | Warum |
|---|---|---|
| carta | Karte | Wie in Anki und allen Karteikarten-Apps; «Karteikarte» nur, wenn es eindeutig sein muss. |
| carte del ripasso | Lernkarten | Das Wort, das jede:r kennt. |
| ripasso / ripassare | Wiederholung / wiederholen | «Wiederholen» ist das Verb der Lern-Apps (und des Erkenners: «Mathe 2 wiederholen»). |
| Ripeti (la funzione «ripeti» in aula) | Nochmal | Der Befehl heißt «nochmal»; «wiederholen» ist schon für die Karten vergeben. |
| esame | Prüfung | Neutral für Klausur und mündliche Prüfung. «Klausur» nur, wo es klar schriftlich ist. |
| appello | Prüfungstermin | In Deutschland gibt es keine «appelli»: es ist der Termin. |
| sessione (d'esami) | Prüfungsphase | So heißt sie an deutschen Unis. |
| libretto | Notenübersicht | «Transcript of Records» ist zu lang; an der Uni sagt man «Notenübersicht» oder «meine Noten». |
| voto | Note | — |
| media | Schnitt | «Notenschnitt», kurz «Schnitt», so redet man. |
| CFU / crediti | ECTS (Leistungspunkte, LP) | Bei italienischen Prüfungen sind es CFU = ECTS; im Text «ECTS». |
| trenta e lode / lode | 30 cum laude | Italienisches Notensystem: bleibt als Begriff, «cum laude» versteht man. |
| base di laurea (su 110) | Abschlussbasis (von 110) | Gibt es nur im italienischen System: bleibt erklärt, nicht übersetzt in eine deutsche Note. |

| crocette (quiz) | Quiz (Multiple Choice) | So heißt es an der Uni und in Moodle. |
| programma d'esame | Prüfungsstoff | Was in der Prüfung drankommt. Befehl: «Prüfungsstoff für …». |

| esercizio | Aufgabe / Übung | «Aufgabe» bei Prüfungen, «Übung» beim Programmieren. |
| piano (fino all'esame) | Lernplan / Plan | «Plan» kurz, «Lernplan», wenn es klar sein muss. |
| piano di oggi | Plan für heute | So fragt man auch: «Plan für heute». |
